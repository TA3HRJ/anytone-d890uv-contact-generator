How to import

  1. Download the CSV file for your region.
  2. Open the AnyTone CPS software.
  3. For DMR go to DMR > Digital Contact List; for NXDN go to NX > NX Digital Contact List.
  4. Use Tool > Import and select the CSV file.
  5. Write the codeplug to the radio.
